# PenguLab 2.7.0

PenguLab 2.7.0 replaces the coarse desktop/tablet dashboard grid with a free 8 px canvas editor.

## Highlights

- Equal **8 px snap horizontally and vertically**.
- Free drag and resize on desktop and iPad.
- Existing layouts are measured and converted from their actual rendered pixel geometry when the new editor is used for the first time.
- Widgets still make temporary room for the tile being moved.
- iPhone keeps the simpler one-column editor and mobile size presets.
- New installations use the canvas layout from the start.
- README now includes anonymized Dashboard and IP Manager screenshots; the existing header image remains unchanged.
