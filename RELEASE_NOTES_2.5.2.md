# PenguLab 2.5.2

A small dashboard polish release focused on saving space and removing duplicated labels.

## Changes

- Clock widgets no longer show the extra `Zeit` title bar in normal dashboard view.
- Integration widgets such as Pi-hole, AdGuard Home, OPNsense, Proxmox, PBS and Zabbix no longer repeat the integration name in a separate title bar.
- RSS/News keeps its title bar.
- A manually configured custom widget title is still shown.
- During layout editing, widget headers remain visible so settings, remove and drag controls stay accessible.
