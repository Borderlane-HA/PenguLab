# PenguLab 2.5.0

PenguLab 2.5.0 focuses on easier dashboard editing on touch devices and expands infrastructure monitoring.

## Highlights

- Touch-friendly dashboard editing with whole-tile drag and temporary automatic reflow.
- Larger remove/resize controls while editing.
- Logout button in the dashboard header.
- Cleaner login page.
- PBS task rows can be enabled individually, including separate Tape Backup and Tape Restore options.
- New Docker Engine integration for read-only container/image/host overview.
- New Portainer integration for environments, containers and stacks.
- New one-time `pengulabctl` repair/install helper for older Proxmox LXCs.
