# PenguLab 2.8.0

PenguLab 2.8.0 introduces App Groups — compact, iPhone/iPad-style folders for keeping large homelab dashboards tidy.

## App Groups

- Drag an App widget onto another App and hold briefly to create a folder.
- Drag additional App widgets onto an existing folder to add them.
- Folder tiles preview up to four app icons and show how many more apps are inside.
- Click a folder to open its apps in a clean overlay without leaving the dashboard.
- Rename folders, reorder their apps, add more apps, move an app back onto the dashboard or dissolve the entire folder.
- Create a group manually through **+ Widget → App-Gruppe**.
- PenguLab prevents the same dashboard app from being assigned to multiple groups at once.

The existing 8 px free canvas and smartphone-specific editor remain unchanged.
