# PenguLab 2.3.0

PenguLab 2.3.0 focuses on dashboard density, branding and richer infrastructure widgets.

## Highlights

- New PenguLab penguin logo in the sidebar, login page and browser favicon.
- Home Assistant entity widgets can be much smaller and adapt automatically to their size.
- Zabbix recent-problem count is configurable.
- OPNsense gateway latency uses the current gateway status endpoint.
- OPNsense WireGuard widgets can show peer status and latest handshakes.
- Refreshed login experience and favicon cache busting.
